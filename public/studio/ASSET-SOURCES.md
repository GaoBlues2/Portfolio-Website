# Studio asset provenance

The local hero uses the original publicly served studio model and baked textures from https://www.leoparpeix.com/ as specifically requested for a visual recreation. Assets are third-party artwork, not original work by Ethan or this repository's author. No license grant is asserted by this document.

- scene.glb: https://cdn.leoparpeix.com/assets/models/home/scene_v9.glb
- Tex{Fleur,Props,Mobilier,Tableaux,Bibli,Floor,Walls}.ktx2: https://cdn.leoparpeix.com/assets/textures/home/scene-ktx/4096/
- cloud1.png through cloud6.png: https://cdn.leoparpeix.com/assets/textures/global/clouds/
- Decoder files in basis/ and draco/: copied from the already-installed Three.js examples libraries; respective upstream licenses apply.

The React integration, camera interaction, controls, and layout are implemented locally. This recreation has not been published.
